# Mac 初始化分析与原生原型

用户已同意先测量首帧各阶段开销、实现最有价值的原生原型，并要求新分支。分支为 `perf/macos-native-prototype`，基于 `803ff96`。

保留默认CPU/Numba+MPS实现及官方权重。增加可选的、线程隔离的分阶段计时：模型构建、深度处理、候选生成、每轮渲染/裁剪/网络/姿态更新以及评分。MPS计时使用明确同步，报告包含父子阶段的包含时间和独占时间；同步计时不能直接当作最终运行速度。

先使用已保存的RGB-D、掩码和内参做可重复测试，无需再次访问相机管理员权限。保持252候选、初始化5次细化、跟踪2次细化和批次8一致。依据实测选择渲染或网络瓶颈做原生原型，默认不切换；用未插入分段同步的A/B运行比较耗时与位姿。若渲染值得优化，优先实现Objective-C++/Metal批量光栅化，使用Python C ABI包装接入现有网络；这不是整个工程的纯C++移植。

验收：阶段计时总量自洽；关闭计时时不增加GPU同步；原生几何、遮挡、纹理与XYZ测试；使用官方权重对相同输入做数值与速度对照。原型若不能加速必须如实报告，不能以减少候选/迭代混入性能收益。代码、构建方法和结果提交到新分支。
