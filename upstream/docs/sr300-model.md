# SR300_step_target_M4 实物接入

- 文件：项目根目录 `SR300_step_target_M4.stl`，原始文件保留。
- 实物尺寸：180×140×38mm，用户已确认；启动时缩放0.001转换为米。
- 实物颜色：白色，用户已确认；启动时覆盖模型渲染RGB为255/255/255。STL本身不提供纹理，此设置不修改原文件。
- 网格：3504个顶点、7032个三角面，单连通、封闭且面朝向一致；软件渲染检查通过。
- 保留CAD坐标：模型范围为[0,0,0]到[180,140,38]mm，输出位姿对应原始CAD原点。

## 启动

```bash
cd FoundationPose/upstream
sudo ./run_sr300.sh
```

使用sudo是已实测的macOS USB设备权限要求。首帧冻结后，沿白色阶梯件的完整外轮廓点击多边形（包括底板），Enter确认；初始化期间保持相机和物体不动。随后采集30Hz，推理读取最新可用帧，丢弃积压输入。

初始位姿仍需用实物验证，白色材质与毫米缩放检查通过不等于定位精度验收。原点在CAD角点，坐标轴不一定在物体中心；绿色3D框应覆盖整个零件。

仅检查路径和权重、不打开相机：`./run_sr300.sh --check`。
