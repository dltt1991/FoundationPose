# Mac 本机验证记录

日期：2026-10-29。机器：Apple M4 MacBook Air，10 核 GPU，24GB。代码基线：`a1b694b`。依赖版本见 `macos-environment.txt`。以下均为本机实际输出，不是论文成绩。

## 功能与跟踪

- 官方两个预训练权重成功加载到 MPS。
- 官方 mustard0 全部 737 帧完成首帧估计与逐帧跟踪，输出：`debug/mac-mustard0-full/`。人工查看首帧及末帧叠加，框覆盖瓶身，末帧已包含机器人抓取后的位姿。
- 首帧使用官方给定 mask，渲染轮廓与该 mask 的 IoU 为 0.9142。这是初始化输入一致性检查，不能作为独立精度评测。
- 原流水固定 30Hz 回放会加速动作，引起失跟踪。修复为按纳秒时间戳回放后，完整序列处理 578 次位姿更新，输出 `debug/mac-pipeline-timestamps/`。相对全 737 帧逐帧版本，在相同帧 ID 对照：平移差中位数 0.0854mm、最大 1.5175mm；旋转差最大 1.3467°。这是两种实现的一致性检查，数据包没有真值位姿，不能等同实际定位误差。
