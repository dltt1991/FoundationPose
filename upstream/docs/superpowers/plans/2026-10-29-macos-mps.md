# Mac 本机离线版本实施计划

**Goal:** 在 Apple Silicon 上使用官方 FoundationPose 权重完成 model-based 离线估计及跟踪。

**Architecture:** 保留上游网络和算法，显式配置 torch 设备；CPU 光栅化、过滤与聚类替代 CUDA 专用算子。新增离线入口及 RealSense RGB-D 入口。

**Tech Stack:** Python 3.11、PyTorch MPS、NumPy、Numba、OpenCV、trimesh。

## 约束

- 不训练新权重；不改模型参数结构。
- 不删除或覆盖已有演示输出；不引入全局 CUDA/MPS monkey patch。
- 有限批次执行卷积，评分的跨候选注意力保留全体候选。
- 相机未连接不声称通过实机验证；性能以实测为准。
