# FoundationPose Mac 离线原型

用户已同意实现 Mac 本机版本，机器为 M4 / 24GB，后续使用 RealSense。

首期保留官方 model-based 网络和权重、候选旋转、细化和评分算法。张量运算使用 MPS（CPU 可用于排错），Numba CPU 光栅器替代 nvdiffrast，CPU 内核实现原始深度过滤和位姿聚类。CUDA 路径继续使用原依赖。新增独立离线入口，保存逐帧 4×4 物体到相机变换、叠加图和计时；不删除已有输出。RealSense 使用对齐到 RGB 的米制深度、标定内参和首帧分割掩码，作为第二阶段入口。

验收：合成几何验证遮挡、透视插值、裁剪和深度；CPU/MPS 网络前向检查；获取官方权重和示例后运行首帧与跟踪。没有权重、数据或相机时明确记录未验证项目。软件渲染器不做训练梯度，不承诺与 CUDA 像素级一致或实时帧率。
